## 🔎 Enumeración

En este nivel encontramos un binario con permisos SetUID en el directorio personal.

🎯 Objetivo: ejecutar el binario correctamente para obtener acceso a la contraseña del siguiente nivel, ubicada en /etc/bandit_pass.

🧠 Concepto: permisos SetUID en Linux y cómo pueden permitir ejecutar un programa con los privilegios de otro usuario.
