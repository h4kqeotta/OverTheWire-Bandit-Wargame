## 🔎 Enumeración


En este nivel, un programa se ejecuta automáticamente mediante cron a intervalos regulares.

🎯 Objetivo: analizar la configuración en /etc/cron.d/ y crear nuestro primer script de Bash para aprovechar el comportamiento del programa y obtener la contraseña.

🧠 Concepto: introducirse en la automatización con shell scripts, permisos de ejecución y tareas programadas con cron.

💡 Pista: el script que creemos será eliminado después de ejecutarse, así que conviene guardar una copia.
